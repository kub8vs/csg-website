# CSG – strona „wkrótce”

Statyczna strona (czysty HTML, bez frameworka). Każdy push na `main` automatycznie publikuje się na Vercelu.

Pliki: `index.html`, `csg-logo.svg` (zębatka + CSG, wektor z oryginalnego EPS, też jako favicon).

Zmiana telefonu / maila: w `index.html` podmień tekst i linki `tel:` oraz `mailto:`.
